# 危险品集装箱配载台

面向港口配载员的危险品集装箱配载作业台（纯前端，React + TypeScript + Vite）。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建（tsc + vite）
npm run preview  # 预览构建产物
```

## 功能

- **录入**：箱号（ISO 6346 校验位核验）、重量、IMDG 危险类别、冷藏需求、卸货港（按靠港顺序）。
- **配载**：6 倍位 × 6 列 × 4 层船图，拖放或点选配载，支持移回待配池、跨倍位移箱、锁位。
- **实时全量复核**（移箱 / 锁位 / 批量重排后自动重跑并写入操作链）：
  - 危险品隔离（简化 IMDG 隔离表：远离 / 隔离 / 严禁三级）
  - 左右偏心（偏心矩限 ±60 t·列）
  - 冷藏供电（每倍位插座上限）
  - 靠港先后（堆内须晚卸在下、早卸在上）
  - 叠放限制（单堆 100t、重不压轻 ±5t、1 类爆炸品置顶）
  - 每项冲突均指明涉及箱号与触发规则，支持定位与一键处置。
- **确认门禁**：存在未解除冲突 / 待裁定项 / 待配箱时无法确认方案；确认后任何变更自动失效。
- **双端协同**：开两个标签页即两名配载员（BroadcastChannel 同步）。同时改同一箱时两份修改都保留，弹出逐字段人工裁定，绝不静默覆盖。
- **持久化**：方案与操作链写入 localStorage，刷新自动恢复。
- **场景演练**：一键演示「录入→配载→复核→处置→确认」全流程；可单独注入隔离违规 / 偏心超限 / 供电争抢 / 靠港颠倒 / 叠放违规 / 并发改箱场景核对规则引擎。
